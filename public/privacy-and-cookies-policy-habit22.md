## § 7 Cookies and Local Storage Technologies

The Shop **habit22.eu** uses technologies to store information on the user's end device (computer, tablet, phone) to ensure the proper functioning of all Shop features.

### 7.1. What are cookies and Local Storage?
* **Cookies:** small text files sent by the server and saved by the user's web browser.
* **Local Storage:** technology built into modern browsers that allows storing data locally without an expiration date (this data is more durable and is not automatically sent to the server with every HTTP request, speeding up the application).

### 7.2. What data do we store and for what purpose?
We only use technologies necessary to provide services electronically and improve the comfort of using the Shop. **We do not use advertising or remarketing cookies or tracking pixels from third parties (e.g., Meta Pixel, Google Analytics).**

The following data stored locally is used in the Shop:

| Name/Key | Technology | Purpose | Storage Time |
| :--- | :--- | :--- | :--- |
| `cart` | Local Storage | Storing the content of the shopping cart (selected bags and their quantity) to allow finishing the purchase. | Until the browser memory is cleared by the user or the cart is manually emptied. |
| `auth_token` or related login session data | Local Storage / Cookie | Maintaining the active session of the logged-in user (so that there is no need to log in again when moving between pages). | Until logout or session expiration (up to 14 days). |
| `lang` | Local Storage | Remembering the chosen language of the Shop interface (PL / EN). | Stored permanently (until browser memory is cleared). |

### 7.3. Managing Cookies and Local Storage
1. **Necessity of operation:** Storing data in the above scope is necessary for the proper functioning of the cart and customer account. Disabling these technologies in the browser will prevent making purchases in the Shop.
2. **Browser settings:** The user can change the settings of their web browser at any time to block cookies and Local Storage or delete already saved files. Detailed information on how to manage these technologies is available in the browser help section or settings:
   * Google Chrome
   * Mozilla Firefox
   * Safari
   * Microsoft Edge
   * Opera
